# Product

## Register

product

## Users

Developers who supervise coding agents across desktop and mobile while reading long transcripts, inspecting tool activity, and steering active work.

## Product Purpose

Provide a calm, legible thread workspace where prompts, agent replies, commands, and artifacts can be scanned quickly without UI chrome competing with the work.

## Brand Personality

Quiet, precise, native. The thread should feel as focused and trustworthy as a first-party developer tool.

## Anti-references

Avoid colorful dashboard styling, stacked cards, persistent status badges, oversized controls, and message chrome that gives routine agent activity the same weight as the conversation.

## Design Principles

- Keep the conversation primary and make machine activity recede.
- Reveal metadata on demand instead of repeating it in every message header.
- Preserve authored content exactly, including whitespace, code, and formulas.
- Use familiar controls and predictable responsive behavior.
- Match desktop density while keeping touch targets and disclosures usable on mobile.

## Accessibility & Inclusion

Target WCAG 2.1 AA contrast, keyboard-operable controls, visible focus, reduced-motion compatibility, semantic timestamps, and equivalent hover and touch interactions.
